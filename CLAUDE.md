Full plan: `/Users/tarowy/Project/Agent/agent-dev-context.md`. Current task brief: `/Users/tarowy/Project/Agent/tasks/`.

## Project facts
- Python, `openai` SDK against an **OpenAI-compatible endpoint** (custom `base_url`), with a hand-written agent loop. Primarily the Responses API, called statelessly (`store=False`, history managed in code, no `previous_response_id`).
- `OPENAI_API_KEY`, `OPENAI_BASE_URL` and the model name (`CODEX_MODEL`) come from `.env` via `share/env_loader.py` — never hardcode them, never print them. Token cost helpers live in `share/usage.py`.
- Python env: **uv** (`pyproject.toml`, `uv.lock`, `.venv`; Python pinned in `.python-version`). Add dependencies with `uv add`, run with `uv run`. `requirements.txt` is generated by `uv export` — don't edit it by hand.
- `from share import ...` needs the project root on the path: VS Code sets `PYTHONPATH`; in a terminal run `PYTHONPATH=. uv run <script>`.
- Model output (tool inputs) is untrusted: no `eval()`/`exec()` on it.
- `Agent-Learning-Plan/` is a gitignored symlink to `~/Project/Agent` (plan, task briefs, notes).
- Tasks so far: `tasks01/01_hello.py` (first API call, multi-turn), `tasks01/02_calculator.py` (first tool + loop with step limit). Task 01 is done; lessons in `Agent-Learning-Plan/notes/01-lessons.md`.
